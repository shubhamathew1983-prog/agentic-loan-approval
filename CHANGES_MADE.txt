 BONUS: CRITICAL BUGS FIXED
─────────────────────────────────────────────────────────────────────────────────

BUG 1: Confidence calculation always > 100
  File: app/agents/base_agent.py
  Issue: _calculate_confidence() multiplies already-scaled (0-100) factors by 100
  Result: Confidence scores were 4000-10000 instead of 0-100
  Fix: Remove the * 100 multiplier
  Impact: Decisions now use correct confidence thresholds

BUG 2: Undefined variable in GET /applications/{id}
  File: app/api/routes.py, line 106
  Issue: Return uses app_id instead of application_id (path parameter)
  Result: NameError when checking application status
  Fix: Change app_id → application_id
  Impact: Status endpoint now works correctly

BUG 3: Async event loop conflict in background tasks
  File: app/api/routes.py, line 76
  Issue: background_tasks.add_task(asyncio.run, run_orchestration())
  Result: asyncio.run() creates new event loop, conflicts with FastAPI's loop
  Fix: background_tasks.add_task(run_orchestration) [no asyncio.run wrapper]
  Impact: Background orchestration now runs correctly

BUG 4: Applicant profile not stored for MCP lookup
  File: app/api/routes.py, after create_application
  Issue: ApplicantDB MCP tries to lookup applicant but profile never stored
  Result: MCP get_income_stability() and get_employment_risk() always return 404
  Fix: Added storage.create_applicant(request.applicant_profile.dict())
  Impact: MCP applicant lookups now successful
